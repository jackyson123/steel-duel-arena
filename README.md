# 機動競技場：鋼鐵對決 / Steel Duel

一個以《高達 VS》街機系列為靈感的 3D 競技場機甲對戰原型。
專案以 Three.js r186 / WebGPU 撰寫，所有場景、機體與特效皆為程式化幾何體與純色材質，沒有載入任何外部模型或貼圖。

> 此儲存庫是 Wanaka Studio 專案的遊戲原始碼（`game/` 內容）。請在 Wanaka Studio 中開啟專案以執行完整遊戲。

## 玩法

- **強制鎖定**：機體持續面向鎖定目標，目標上方顯示鎖定準星；有效時紅色，遭障礙遮蔽或超出射程時轉綠。
- **推進系統**：按住推進鍵飛行；雙擊方向鍵或按 Shift／觸控衝刺鈕進行推進衝刺。落地後推進槽回復，耗盡會進入過熱硬直。
- **光束步槍**：消耗彈藥並隨時間自動填裝；射擊後有收招硬直。
- **近戰斬擊**：向前追擊目標，命中造成傷害與擊飛；可用推進衝刺取消射擊後搖。
- **99 秒決鬥**：擊破敵機或時間結束時以剩餘耐久判定勝負。
- **三架可選機體**：
  - RX-01 蒼藍（平衡）
  - RX-02 疾風（高機動、推進槽更大）
  - RX-03 重裝（高耐久、高火力）
- **手機操作**：虛擬搖桿移動，右側按鈕推進／衝刺／斬擊／射擊；桌面同時支援 WASD、滑鼠與鍵盤。

## 操作

| 動作 | 鍵盤／滑鼠 | 觸控 |
| --- | --- | --- |
| 移動 | WASD | 左下虛擬搖桿 |
| 推進／飛行 | Space（按住） | 推進按鈕（按住） |
| 推進衝刺 | Shift 或雙擊方向鍵 | 衝刺按鈕 |
| 光束步槍 | 左鍵 或 J | 射擊按鈕 |
| 近戰斬擊 | 右鍵 或 K | 斬擊按鈕 |
| 開始／再戰 | Enter 或畫面按鈕 | 畫面按鈕 |

## 場景

- 架高的屋頂競技場，具邊界牆、能量護欄與四角照明塔。
- 六個大型障礙物改為具有窗格、樓層帶、入口雨棚、招牌、屋頂機組與警示燈的程式化建築。
- 背景為三層城市天際線，包含退縮塔身、屋頂設備、數千個程序化窗格燈光、街道網格與路燈。
- 黃昏夜景色調，暖色主光、冷色補光與霧氣。

## 專案結構

```
.
├─ game.ts                 # defineGame 組合根
├─ play.ts                 # 遊戲流程、輸入、相機、戰鬥與 HUD 綁定
├─ scenes/
│  ├─ main.ts              # 競技場、城市、機體場景
│  └─ mech.ts              # 程式化機甲模型與配色
├─ ui/
│  ├─ hud.ts               # HUD、標題、機體選擇、觸控介面
│  ├─ audio.ts             # WebAudio 合成音效
│  └─ look.ts              # UI 主題
├─ arena.ts                # 競技場碰撞與視線查詢（純邏輯）
├─ mechs.ts                # 機體目錄與數值
├─ visual.ts               # Visual Profile
├─ rendering.ts            # 渲染管線設定
└─ unit_test/              # node:test 單元測試
```

## 開發

在 Wanaka Studio 開啟專案即可預覽與測試。純邏輯單元測試可在原始碼根目錄執行：

```bash
npm install
npm test
```

測試使用 `tsx` + `node:test`，不依賴 Three.js 或瀏覽器。

## 素材

本專案不包含任何外部 3D 模型、貼圖或音訊檔案；所有視覺與音效均於執行時程式化生成。
